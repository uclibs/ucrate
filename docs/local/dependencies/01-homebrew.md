# 1) Homebrew

Back to setup index: [docs/local/README.md](../README.md)

Use this step to make sure package management works on your Mac.

## Check

```bash
brew --version
brew --prefix
```

Expected: both commands print values.

## If missing

Install Homebrew from the official script on https://brew.sh.

After install, open a new terminal and run:

```bash
brew --version
```
